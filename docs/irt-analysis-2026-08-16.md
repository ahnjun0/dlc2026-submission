## 0. 왜 IRT였나

두 달간 우리는 **정확도(맞은 문항 수)** 하나로 모든 판정을 했다. 그 지표로는 답할 수 없는
질문이 셋 있었고, 34개 축을 닫고 나서야 그 질문이 필요해졌다.

1. **표를 늘려도 안 풀리는 문항이 몇 개인가** — 집계 축의 물리적 천장
2. **학습이 능력을 실제로 옮겼는가** — 34축이 닫힌 이유가 *우리가 못 찾아서*인지 *안 움직여서*인지
3. **다음 1%p는 어디에 있는가** — 남은 예산을 어디에 쓸지

IRT 2PL은 문항마다 **난이도 `b`**·**변별도 `a`**를, 응답자마다 **능력 `θ`**를 추정한다.

```
P(정답 | θ) = 1 / (1 + exp(−a·(θ − b)))
```

### 설계 — 응답자를 무엇으로 볼 것인가

우리 데이터는 (모델 × 문항 × 32표)라 표준 (응답자 × 문항) 행렬이 아니다. 셋을 검토했다.

| 안                                                      | 내용                         | 판단                 |
| ------------------------------------------------------- | ---------------------------- | -------------------- |
| (a) 응답자 = 모델, 응답 = maj@32                        | 응답자 16명                  | 2PL 추정 불안정      |
| (b) 응답자 = 모델, 응답 = 정답 표 수                    | 이항 IRT                     | 표 간 독립 가정 필요 |
| **(c) 응답자 = 샘플링 체인 (모델, 블록, 표번호)** | **1,472명 × 460문항** | **채택**       |

(c)를 택한 이유: 같은 모델의 32표는 **같은 θ에서 독립 추출**이므로
**모델 내 분산 = 표 하나의 능력 변동**, **모델 간 분산 = 학습이 실제로 옮긴 양**이 된다.
질문 ②를 직접 답한다.

### 추정에서 만난 함정 둘 (기록해 둔다)

**① `(a, b)` 모수화의 Newton은 발산한다.** `a`와 `b`가 곱으로 얽혀 Hessian이 비정부호가 되고
경계로 튄다(실측: `a`가 상한 6.0에 붙고 `θ`가 격자 끝 +4로 몰림). **선형 모수화
`logit P = α·θ + β`로 바꾸면 전역 오목이라 IRLS가 안정적**이고, 끝에 `a=α, b=−β/α`로 환산한다.

**② `θ ~ N(0,1)` 고정은 이봉 분포에서 퇴화한다.** 문샷이 나머지와 크게 다르면 두 봉우리가
격자 끝으로 밀려난다. **Bock–Aitkin 방식의 경험적 사전**(사후의 응답자 평균)을 쓰고
매 반복 "평균 0·표준편차 1"로 재척도해야 한다.

## 1. 문항의 3분의 1이 능력과 무관하다

`exp-069_irt` (결정성 16개 모델-블록, 512 응답자)

```
460문항 = 적합 411 + 전원 정답 31 + 전원 오답 18

변별도 a < 0.2 : 105문항 (25.5%)
        a < 0.3 : 125문항 (30.4%)
        a < 0.5 : 169문항 (41.1%)
a 중앙 0.651 · p10 0.020 · p90 1.894
```

**중요한 건 이것** — `a<0.3` 문항의 관측 정답률 중앙은 **0.707**(p10 0.08 · p90 0.99)이다.
**어려워서 변별이 안 되는 게 아니라, 쉽든 어렵든 능력과 무관하게 결정되는** 문항들이다.

`31 + 18 + 105 = 154문항(33%)`이 변별에 거의 기여하지 않는다.
**460문항 val은 실질적으로 300문항짜리다.**

## 3. 다음 1%p의 좌표

```
우리 θ = +0.368   I(θ) = 11.1   SE(θ) = 0.300
최대 정보는 θ = −3.00 에서 49.7        ← 문샷이 있는 자리

|b − θ| ≤ 0.2 인 문항 :   5개
|b − θ| ≤ 0.5 인 문항 :  12개
b < θ (이미 쉬움) 312 · b > θ 99
```

**θ를 조금 올려서 얻을 수 있는 문항이 5개다.** 그리고 우리 검사는
**θ=−3(문샷 수준)에서 정보가 최대이고 우리 수준에서는 최대값의 22%밖에 안 된다.**

### 선별로는 정밀도가 안 오른다 (초기 오판 정정)

정보는 가법적(`I = Σ I_i`)이므로 **부분집합의 정보는 항상 전체 이하**다.

```
상위 K      누적 정보   전체 대비    SE(θ)    문항당
 50          7.55      68.0%     0.3639   0.1510
150         10.55      94.9%     0.3079   0.0703
411         11.11     100.0%     0.3000   0.0270

정보 기여 < 0.01 인 문항: 259개 (63.0%)
```

150문항으로 줄여도 SE는 `0.3000 → 0.3079`로 2.6%밖에 안 나빠지지만 **개선도 없다**.
**선별이 사는 것은 정밀도가 아니라 정보당 생성 비용**이다(생성량 63% 절감, 정보 95% 유지).

정밀도를 올리려면 문항을 늘려야 한다. `SE 0.15`에는 현 밀도로 **1,644문항**이 필요하다.

### 그런데 붙일 문항이 없다 (실측)

| 후보          |   문항 | 길이중앙 | LaTeX | 답중앙 | 판단                  |
| ------------- | -----: | -------: | ----: | -----: | --------------------- |
| val460 (현행) |    460 |      201 | 28.3% |     26 | 기준                  |
| train_split   | 16,500 |      203 | 27.0% |     30 | 기준과 일치           |
| AIME          |     90 |      289 | 78.9% |    215 | **분포 불일치** |
| AMC           |     83 |      264 | 71.1% |     12 | **분포 불일치** |
| MATH-L4       |    744 |      148 | 48.8% |     14 | **분포 불일치** |
| MATH-L5       |    719 |      184 | 55.2% |     23 | **분포 불일치** |

`train_split` 16,500 중 **sft_v2 학습에 안 쓰인 것은 1,247개**뿐이고,
그것들은 **STaR가 실패한 문항**(길이중앙 237·답중앙 93)이다.
*"v2가 못 푼 것"*으로 선택된 집합이라 val로 쓰면 **회귀-평균이 개선처럼 보인다**.

## 4. 그래서 나온 진짜 발견 — 우리는 9배 둔한 자를 썼다

같은 생성물에서 두 지표를 뽑을 수 있고, 정밀도가 9배 다르다.

```
maj@32 점수   시드 간 표준편차  0.47%p     ← 두 달간 쓴 지표
θ (능력)      모델 평균 SE      0.0158

환산: dθ = 0.05 → 0.163%p 이므로 0.47%p ↔ dθ = 0.144
      0.144 / 0.0158 = **9.1배**
```

`maj@32`는 32표를 뽑는 우연까지 통째로 삼킨다. `θ`는 460문항 × 32샘플의
**개별 응답 14,720개**를 전부 써서, 다수결 집계에서 버려지는 정보를 회수한다.

**그리고 둘은 다른 질문이다.**

| 질문                                        | 지표         | 분산 |
| ------------------------------------------- | ------------ | ---- |
| *"이 변경이 모델을 낫게 만들었나"* (과학) | **θ** | 낮음 |
| *"D-Day 점수가 오르나"* (공학)            | maj@32       | 높음 |

우리는 첫 번째 질문을 두 번째 자로 재 왔다.

### 5-a. 되살아난 축 셋

**`exp-024` 외부 STaR 확장이 가장 확실하다** — 4블록씩 짝지어 `z=4.06`.
우리는 이걸 *"−0.22%p, P=32.2%"*로 닫았는데 **모델은 실제로 나아졌다**.
`exp-035` 경시 STaR와 `exp-067` 체크포인트 평균도 θ 기준으로 개선이다(단 1블록).

### 5-b. 그런데 반대 방향이 더 중요하다

**`mix`는 θ가 −0.16으로 무학습 baseline보다도 낮은데 `maj@32`는 82.39%로 v2보다 높다.**
`para`·`DPO`도 같은 패턴이다.

```
θ↑ · maj@32 →    exp-024 외부STaR · exp-035 경시STaR      "더 잘하게" 만든 축
θ↓ · maj@32↑    exp-018 mix · exp-060 para · DPO         "더 다르게" 만든 축
```

> **다수결은 능력이 아니라 오류의 비상관성을 보상한다.**

우리는 두 달간 θ를 올리는 축(SFT 계열)만 팠고, 그게 maj@32에 안 나타나는 걸
*"축이 죽었다"*로 읽었다. **이건 파트너 물리학과 같은 법칙이다** — 그때는 *두 모델 사이*에서
봤고 지금은 *한 모델 안의 32표*에서 본다.

> *"파트너 가치 = 강함이 아니라 다름"*  →  **"다수결 가치 = 능력이 아니라 다양성"**

## 6. 정직하게 붙이는 단서

1. **1블록 비교(`exp-035`·`ckpt평균`·`mix`·`exp-045`)는 SE를 가정값으로 썼다**
   (θ: 0.13/√32, maj@32: 0.47%p). `z`가 실제보다 낙관적일 수 있다
2. **θ 개선이 배포 이득을 보장하지 않는다.** 우리 점수는 `maj@32`다.
   실제로 오늘 반례를 쟀다 — 문샷 2048→8192는 **단독 +4.13%p인데 풀링 ±0.00**이었다
3. **`clean v2`는 θ 미측정(z=1.53)인데 maj@32는 악화(z=−2.10)** — 방향이 반대라
   이 대조군 자체가 흔들린다. `exp-024`의 `z=4.06`은 이 대조군에 의존한다
4. **구 500문항 파일을 460 교정 id로 제한**해 썼다. 생성 체제(결정성 여부·max_tokens)가
   블록마다 다르므로, **같은 체제 안에서만** 비교했다
5. **문항 모수가 이 46개 모델에 조건부**다. 다른 모델군에서는 `a`·`b`가 달라질 수 있다

## 7. 이것이 바꾸는 것

**바꾸지 않는 것**: D-Day 구성은 **v2 32표 + 문샷 8192 32표 전량 풀링** 그대로다.
LB에서 실증된 유일한 이득이고, θ 재판정은 배포 판정이 아니다.

**바꾸는 것**:

- 앞으로 **학습·구조 축은 θ로 1차 판정**하고, 통과분만 maj@32로 배포 판정한다 (9배 정밀)
- **"θ↓ · maj↑" 프로파일을 파트너 후보의 지문으로 쓴다** — `mix`·`para`가 정확히 그 모양이다
- 축 지도에 **"미측정"** 상태를 신설한다. `|Δ| < 0.5%p`로 닫은 축은 사망이 아니었다

## 8. 후속 진단 (같은 날) — "아주 가끔 푸는 문제"의 정체

구역 분석에서 **A구역 46문항이 `pass@64 85.3%` vs `maj@64 26.1%`**로 나왔다.
정답이 64표 중 평균 2.2표 나온다는 뜻이다. 그 2.2표가 무엇이 달랐는지 추적했다.

### 8-1. 첫 수(first move) 진단 — 신호 없음 (`exp-071_first_move`)

결과 오염(정답이라서 생긴 차이)을 피하려고 **앞 200자만** 썼다.
근거는 우리 자체 실측 *"정답 풀이와 다수 오답 풀이의 공통 시작 5% — 접근부터 갈린다"*.
문항 5겹 교차검증 + 문항 내 rank AUC.

```
구간              구출가능 지대     전체
head (앞 200자)     0.5138       0.5423
mid  (중간 200자)    0.5174       0.5518
tail (끝 200자)     0.5493       0.6075     ← 답이 들어 있는데도 0.55
null (라벨 셔플)     0.5047         —        ← 계기 정상
```

**`char/word n-gram`으로는 구분되지 않는다.**

### 8-2. 그러나 사람이 읽으면 구분된다 — 방법론 교훈

*"텍스트 수준에서 구분되지 않는다"*고 보고했다가 **표본을 직접 읽으라는 지적**을 받고 읽었다.
세 문항 모두 사람은 즉시 구분했고, 단서는 **어휘가 아니라 의미**에 있었다.

| 문항 | 무엇이 달랐나 | 후속 |
|---|---|---|
| `train-000250` | 추론이 **완전히 동일**하고 `\boxed{4}` vs `\boxed{-4}` 뿐 (부호 관례) | 전수 검사 → **460문항 중 1건**. 닫힘 |
| `train-000779` | 오답이 한 문장 안에서 자기모순 (*"같은 병원 불가 → 따라서 같은 병원을 고르자"*) | 의미 판정 필요. `exp-038`(45.9%)이 최근접 |
| `train-001033` | 정답 표가 **답만 맞고 열거가 깨짐** (`2b₂+b₃=6`인데 `b₂`를 6까지 열거) | "계산 우발성" 진단과 정합 |

> **규칙**: 지표의 실패를 대상의 성질로 옮기지 말 것.
> *"X로 구분되지 않는다"*는 **쓴 지표를 명시해서** 진술하고, 대상 주장은 **읽은 뒤에** 한다.

### 8-3. 필요한 능력 상승량 — 경로가 정의상 막혀 있다

2PL에서 `p₀ → p₁`에 필요한 이동은 `Δθ = [logit(p₁) − logit(p₀)] / a` 다.

```
구역            문항   a 중앙    현 정답률
A. 능력무관·실패   46    0.020     0.065     ← 적합 하한. 사실상 0
D. 정상 변별     273    0.795     0.976
```

**`a ≈ 0`은 "많이 필요하다"가 아니라 "θ가 레버가 아니다"는 뜻이다.**
(계산 스크립트가 낸 `470배`류 수치는 **하한에 걸린 `a`로 나눈 인공물**이므로 인용하지 말 것.)
A구역에서 `Δθ ≤ 1.0`(우리 역사상 최대 이동 0.1308의 7.6배)으로 뒤집히는 문항은 **0개**다.

### 8-4. 그래서 "아주 가끔"의 정체

능력에 반응하지 않으면서 6.5%로 성공한다 = **매번 같은 동전을 던지고 있다.**
8월 초 오답 분석의 결론과 정확히 일치한다.

> *"모델은 방법을 알지만(포함배제·약수구조를 첫 문장에 정확히 명시) 다단계 계산에서 붕괴한다."*

**IRT가 그것을 정량화했다** — 붕괴가 능력의 함수가 아니라 잡음이라서 `a ≈ 0`이다.

실행 안정화의 알려진 수단은 셋인데 전부 막혀 있다.

| 수단 | 상태 |
|---|---|
| 계산 외주화 (TIR) | **공식 금지** (8/2 운영진 Q&A) |
| 자기 검증·백트래킹 내장 | long-CoT가 그 행동을 가졌는데 **−4.7%p** (exp-015) |
| 표 증량 | `pass@64` 이미 85.3%인데 `maj@64` 26.1% — 따라오지 않음 |

> **"아주 가끔 푸는 문제"는 "가끔 능력이 닿는 문제"가 아니라
> "능력과 무관하게 가끔 계산이 맞아떨어지는 문제"다.**
> **그래서 능력을 올리는 어떤 학습으로도 "정말 잘"로 바뀌지 않는다.**

### 8-5. 부수 결과 — 3자 풀링은 표 증량 효과였다

```
제3모델      A(현구성 64표)   B(증원 96표)    B−A
mix            82.99         83.64      +0.65
para           82.99         83.64      +0.65

```

**서로 다른 세 모델이 소수점까지 같은 `+0.65`**를 낸다. 제3 모델의 정체가 아니라
**표를 32개 더 준 효과**이며, 표 증량은 이미 닫힌 축이다(`maj@k>32` 곡선 포화).
완전한 표수 대조군에는 **문샷 8192 두 번째 블록**이 필요하다.

## 9. 정정 — "능력과 무관하다"는 틀렸다. **두 개의 능력이 있다**

8-4에서 *"능력과 무관하게 가끔 계산이 맞아떨어지는 문제"*라고 썼다. **틀렸다.**
`a ≈ 0`은 *"능력과 무관"*이 아니라 *"**우리가 관측한 θ 축**에 반응하지 않는다"*는 뜻이다.
θ 자체가 무엇을 재는지 확인하지 않고 능력 일반으로 확대한 것이 오류다.

**적합값이 아니라 원자료로 다시 쟀다** (`src/eval/zoneA_by_model.py`).

```
모델                    θ        A구역    C구역    D구역    B구역
무학습 baseline      +0.180     7.9%    51.1%   83.2%   89.6%
v2 (결정성)          +0.286     8.2%    50.1%   84.2%   90.9%
clean v2            +0.331     8.4%    51.9%   84.4%   91.1%
exp-024 외부STaR    +0.384    10.2%    50.2%   84.9%   91.5%
exp-029 fullFT      +0.232     8.6%    48.8%   83.6%   91.3%
exp-035 경시STaR    +0.369    11.4%    49.4%   84.8%   92.9%
exp-045 8B          +0.326     8.9%    50.9%   84.4%   91.2%
exp-055 확장블록      +0.297     9.6%    52.1%   84.3%   90.8%
exp-067 ckpt평균     +0.320     9.1%    50.3%   84.3%   91.9%
exp-018 mix         +0.126    11.5%    52.6%   82.8%   92.2%
para                +0.234    10.5%    53.0%   83.7%   90.2%
문샷 8192           −2.822    14.7%    57.4%   70.3%   92.0%
문샷 2048           −3.873    10.8%    42.9%   59.5%   84.3%
──────────────────────────────────────────────────────────────
θ와의 상관                    r=−0.586          r=+0.989
```

### 9-1. θ는 고장난 게 아니라 **주류 서술형 능력**을 재고 있었다

**D구역(273문항, 전체의 66%)에서 θ는 거의 완벽하다 — `r = +0.989`.**
문샷 70.3% → v2 84.2%로 깔끔히 정렬된다.

**A구역에서는 부호가 뒤집힌다 — `r = −0.586`.** θ가 가장 낮은 문샷이 **14.7%로 최고**다.

> **능력은 하나가 아니다.** 우리 θ는 **주류 수학 서술형 능력**이고,
> A구역(경시 정수론·조합론)은 **다른 능력**을 요구하며, 우리 모델군 안에서 둘은 **상충**한다.

### 9-2. A구역은 실제로 움직인다 — 그리고 상충 없이 움직인 모델이 있다

```
                    A구역        D구역
v2                  8.2%        84.2%
exp-024 외부STaR   10.2% (+2.0)  84.9% (+0.7)   ← 둘 다 상승
exp-035 경시STaR   11.4% (+3.2)  84.8% (+0.6)   ← 둘 다 상승, A 최대
문샷 8192          14.7% (+6.5)  70.3% (−13.9)  ← A는 최고지만 D를 버림
```

**`exp-035` 경시 STaR가 A를 +3.2%p 올리면서 D도 +0.6%p 올렸다. 상충 없이 양쪽이 오른 유일한 모델이다.**
그런데 우리는 이걸 **1시드 `maj@32` −0.4%p로 닫았다**.

### 9-3. 필요한 상승량 재계산 — 8-3의 "470배"는 인공물이었다

8-3은 `Δθ = [logit(p₁) − logit(p₀)] / a` 에서 **`a`의 적합 하한(0.02)으로 나눈** 값이라
수백 배가 나왔다. **인용하면 안 된다.** 원자료 로짓으로 직접 계산하면 다음과 같다.

```
A구역 다수결 승리선 ≈ 표본 정답률 35%

v2            8.2%   logit = −2.41
exp-035      11.4%   logit = −2.05      ← 한 번의 개입으로 **+0.36**
목표         35.0%   logit = −0.62

남은 거리 1.43 logit ÷ 개입당 0.36 ≈ **같은 개입 4배**
```

### 9-4. 데이터는 있다 — 그러나 반례도 있다

```
contest_pool     36,584문항  (olympiads 28,773 · aops_forum 4,441 · cn_contest 2,950 · amc_aime 420)
frontier (사용분)  4,480문항  ← exp-035가 쓴 것. 풀의 **12%**
미사용            32,104문항  ← 7.2배 여지
sft_contest      23,593건 = sft_v2 19,185 + **경시 4,408건**
```

**그러나 단순 증량은 근거가 약하다** — `exp-024`는 경시보다 **5배 많은 21,827건**(sft_ext 41,012)을
넣고도 A구역 이득이 **더 작았다**(+2.0 vs +3.2). **양이 아니라 종류가 움직였다.**

또 `frontier`는 *"v2가 못 푸는 문항"*으로 골라낸 집합이므로, 풀의 나머지 32,104건은
정의상 **더 쉬운 문항**이다. 그대로 4배로 늘리면 같은 효과가 안 날 수 있다.

**따라서 증량 축은 둘이다.**

| 안 | 내용 | 근거 | 위험 |
|---|---|---|---|
| **(가) 같은 문항 깊게** | frontier 4,480에 `n=8 → 32`로 재채굴 | 문항당 1건 → 여러 건 + n=8에서 놓친 문항 회수 | 같은 문항 반복 = v3(반복 자기증류) 실패 패턴 |
| **(나) 더 많은 경시 문항** | 풀 32,104에서 난이도 상위 추가 선별 | 새 정보 | frontier보다 쉬워 A구역 효과 감쇠 |

**그리고 `exp-036` DPO의 용량-반응 경고가 여기에도 적용된다** — 표적은 계속 개선됐지만
비표적이 따라 내려가 전체는 적자였다. **비표적(D·B구역) 감시가 판정에 포함돼야 한다.**

## 10. exp-035 증량 검토 — **구역 이득이 잡음과 구분되지 않는다**
