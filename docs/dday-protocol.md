### ⚠ 8/10 에 철회한 "캐스케이드" 와 **다른 것**이다 — 혼동 금지

같은 이름이지만 기제가 반대다.

```
8/10 철회한 것   **위임형** — v2 가 임계 14 이상이면 파트너를 **안 돌리고 v2 답으로 대체**
                  전량 풀링과 LB 에서 **8문항** 갈렸는데 **부호를 몰랐다** → 도박이라 철회
exp-101 (채택)   **증원형** — 접전 문항에 **제3 모델(경시STaR)을 추가**로 넣는다
                  전량 풀링 대비 33행이 갈렸고 **부호를 측정했다** → **+3문항**
```

**8/10 의 논리는 지금도 옳다**: *"차이가 나는데 부호를 모르면 최종 test 에서 도박하지 않는다."*
exp-101 이 그 반론을 넘은 방법은 논리가 아니라 **측정**이다 —
같은 생성 배치로 대조군을 재조립해 `sub-012` 와 0행 차이임을 확인한 뒤(짝 고정),
`sub-014` 를 제출해 **665 → 668** 을 직접 읽었다.

**단 정직하게**: LB 단독 McNemar 는 유의하지 않다(33행 변동에 순증 3). 채택 근거의 무게는
val460 **3시드 [+6,+3,+0] · 교차적합 5분할 전부 양수 · P 98.8%** 에 있고,
LB 는 **방향이 뒤집히지 않는다**는 확인이다.

### 두 관문은 하는 일이 다르다 (8/24 문턱 스윕으로 분해)

```
         margin:    0     2     3     5     8    12    20    32
       확정없음    +1    +0    +2    +3    +3    +2    +2    +2
      v2>=32~30    +1    +0    +2    +3    +3    +2    +2    +2
      v2>=28~24    +0    -1    +1    +3    +3    +2    +2    +2
```

**세로로 안 변한다** → `v2 확정 관문(confirm=30)` 은 **정확도에 기여하지 않는다.**
그것이 하는 일은 **문샷 55.6% 생략 = 순수한 시간 절약**이다.
정확도 +3 은 전부 **가로축(경시STaR 조건부 증원, margin=5)** 에서 온다.

→ **시간이 급하지 않으면 confirm 을 꺼도(=99) 점수는 같다.** 두 손잡이를 따로 생각할 것.
→ margin 은 **5·8 이 고원**이라 인접 값에서 안 무너진다 (과적합 아님).

## 5. 리허설에서 배운 함정

| 함정 | 대응 |
|---|---|
| **서버 코드가 구버전** — 로컬에서 고친 거대정수 가드가 배포 안 돼 풀링만 실패 | 1절 체크리스트에 `parse.py` 명시. **v2 단독은 성공하고 풀링만 죽는다** = 발견이 늦다 |
| **집계 쪽에도 같은 병** — `pd.Series.value_counts()`가 거대정수에서 OverflowError | `Counter`로 교체 완료. 파서만 고쳐선 부족했다 |
| 청크가 난이도 덩어리와 겹치면 한 청크가 2시간 정체 | `--chunk 100`으로 잘게 |
| 구 문항 생성물이 섞이면 행 수 초과 | `--expect-ids` 필수, 초과가 정당하면 `--restrict-to-expect` |
| full 모델을 `--lora`로 넘기면 EngineDeadError | 어댑터는 `--lora`, 전체 가중치는 `--model` |
| 체크포인트·모델이 디스크를 채움 | 사전에 20GB 확보. 스테이징 사본은 **복사가 아니라 이동** |
| **작업 중단 후 VRAM 미해제** | kill 뒤 `nvidia-smi --query-compute-apps`로 확인한 **다음에** 새 작업. kill과 launch를 한 명령에 넣지 말 것 (8/10 실측) |
| ssh 세션 의존 감시가 끊김 | 짧은 접속 반복(폴링)으로 상태 확인 |
