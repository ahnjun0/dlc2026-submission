# 3단계 제거 ablation — **사전 등록** (2026-08-26, 제출 전 고정)

외부 검토 판단을 그대로 채택한다. **제출 전에 이 표를 고정하고, 결과를 본 뒤
문턱·멤버·표 구성을 다시 고르지 않는다.**

```
Δ_LB = (3단계 있음 = sub-014 = 668) − (3단계 없음 = 이번 제출)
```

| Δ_LB | 결정 | 해석 |
|---:|---|---|
| **≥ +3** | **유지** | 실용 MDE까지 독립 확인 |
| **+1, +2** | **조건부 유지** | MDE 증명은 아니나 val 과 방향 일치. 리허설 통과를 조건으로 방어 목적 유지 |
| **0** | **제거** | 동률이면 단순한 구성이 우세 |
| **≤ −1** | **제거** | val–LB 부호 충돌. 알려진 val 낙관 편향까지 감안하면 유지 근거 없음 |

**+1/+2 에서 유지하는 것이 MDE 규칙 위반이 아닌 이유** — 두 판정을 분리한다.
```
연구상 주장   +3 미만이므로 «검증된 개선» 이라고 부르지 않는다
배포 결정     이미 구축됐고 val·LB 방향이 같으며 추가 비용이 35분뿐이므로
              작은 양의 기대값을 보존한다
```
이는 게이트 v2 의 **후보성 / 증거수준 / 배포결정** 3단 분리와 일치한다.

**제출은 한 번뿐이다.** 결과를 본 뒤 `margin`·`confirm`·멤버를 재탐색하지 않는다.

## 이번 대조가 깨끗한 이유

`sub-014` 의 668 은 **3단계의 근거가 아니었다** — 그것은 «캐스케이드 전체 vs 전량 풀링»
(`sub-012` 665)의 비교라 1·2·3단계 효과가 섞여 있다.
이번 제거형은 **저장된 출력의 조립만** 바꾸므로 3단계가 유일한 변수다.
추가 생성 0 · 학습 0 · 제출 1회.

## 최종 결정문 (외부 검토 문구 그대로)

> 3단계 제거형을 사전 고정한 상태로 LB 에 한 번 제출한다. 3단계의 LB 기여가 양수이면
> 리허설 통과를 조건으로 유지하고, 0 또는 음수이면 제거한다. +3 미만의 양수는 배포상
> 유지할 수 있으나 검증된 성능 개선으로 주장하지 않는다. 결과 확인 뒤 문턱·멤버·표 구성을
> 추가 탐색하지 않는다.
