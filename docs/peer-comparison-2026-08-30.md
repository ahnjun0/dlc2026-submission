# 동료 파이프라인 대조 + 진단 분할 도입 (2026-08-30 · D-1)

출처: 동료 공개 보고서 `192cm.github.io/projects/qwen25-math-reasoning.html` (같은 대회·같은 베이스).

## 1. 동료 구조에서 가져올 것 — 「구간별 하한」을 우리 게이트에 적용했다

동료의 채택 조건 4개 중 우리에게 없던 것은 **③ hard·format 진단셋에서 −2%p 초과 하락 금지**다.
우리 게이트는 스칼라 하나(부트스트랩 P + LB 짝 검정)라 *"전역 +3인데 특정 구간이 무너지는"*
후보를 원리상 못 잡는다. 동료는 이 조건으로 RFT(Random +0.86%p)를 기각했다.

**우리 배포 구성에 적용한 결과 — 어떤 구간에서도 하락이 없다.**
분할 정의는 생성물과 무관한 구조적 속성만 썼다(사후 선택 회피).

```
분할                             n    STAR 단독   캐스케이드         Δ
Random(전체)                   460     82.39%     83.48%   +1.09%p
출처:gsm8k/orca                222     96.40%     97.75%   +1.35%p
출처:numina/기타               185     72.97%     74.05%   +1.08%p
출처:omni_math                  37     43.24%     43.24%   +0.00%p
출처:unmatched                  16     87.50%     87.50%   +0.00%p
Hard(조합·정수론·기하)          128     59.38%     60.16%   +0.78%p
Format(음수·거대정수)            16     81.25%     81.25%   +0.00%p
Format(LaTeX 밀집 상위25%)     115     67.83%     69.57%   +1.74%p
Format(장문 상위25%)           115     66.96%     68.70%   +1.74%p
```

**최소값이 0.00%p 다.** 이득은 LaTeX 밀집·장문(+1.74%p)에 집중되는데, 이는 캐스케이드
2·3단계가 발화하는 지대와 정확히 겹친다 — 설계 의도가 데이터로 확인된 셈이다.

한계: 이건 «구간별 하락이 없다» 지 «구간별로 유의하다» 가 아니다. omni_math 37문항 같은
소표본에서 ±0 은 판정력이 없다는 뜻이기도 하다.

## 2. 동료가 못 가진 것 / 우리가 못 가진 것

**우리가 더 엄격한 지점 — 동료 결론 셋이 흔들린다.** 동료는 **시드 42 하나**다.
우리 4시드 실측 폭은 **1.96%p (9문항)** 이다. 그 자에 대면 동료의
vote filter +1.47%p · RFT +0.86%p · 96표 다중뷰 +1.98%p 는 **전부 단일 시드 잡음 폭 안**이라
부호조차 보장되지 않는다. 0.03%p 차이로 HOLD 한 것은 측정할 수 없는 차이를 측정한 것이다.
(우리도 8/6 에 같은 오류로 문샷 파트너를 P=92%로 오판해 보류했었다.)

게이트 감도: 동료 +1.5%p = 3,737문항에서 **56문항**. 우리 채택 기준은 LB 831 에서 **+3문항**
(0.36%p) + 부트스트랩 P≥95% + 짝 검정. **우리 3단계(+3문항)는 동료 기준으로는 측정 대상조차 아니다.**

**동료가 가진 것 — Template holdout.** 문항 «틀» 로 분리한 홀드아웃이 있어
*"본 적 없는 표현으로 일반화되는가"* 를 직접 잰다. 우리는 층화 랜덤 하나뿐이다.
이것이 우리 val 편향(`docs/val-bias-2026-08-26.md`, −2.32%p 낙관)과 «분포를 벗어나면
수확 격차가 두 배»(`docs/calibration-2026-08-26.md`)의 **올바른 처방이었다.**
D-1 이라 못 만든다. 다음 대회의 Week 0 항목.

## 3. 파이프라인의 구조적 차이

```
              pass@32    maj@32     격차
동료           84.40%    69.31%   15.09%p   ← 선택 실패가 크다
우리(val460)   90.87%    81.74%    9.13%p
```

동료가 GenSelect·ORM 에 두 축을 투자한 것은 **합리적이다** — 15%p 는 회수 여지가 크다.
우리는 9.13%p 이고 IRT 상 실현 가능분 1.74%p 중 1.32%p 를 이미 취해 남은 게 0.4%p 다.
**같은 기법이 그쪽에선 유망하고 우리에겐 닫힌 이유가 이 숫자에 있다.**

동료의 최대 이득 축(출력 계약, invalid 15.03% → 0.61%, +3.79%p)에서 **우리는 이미 0.2% 다**:

```
STAR 파싱 실패 28/16,000 (0.18%)  ·  LONGCOT 0 (0.00%)  ·  STAR-OLY 1 (0.01%)
```

동료의 향후 과제 2번(*"question-local macro AUC 를 주 지표로"*)은 우리가 8/15 에 이미 규칙으로
세웠다(«블록을 나눠도 문항이 같으면 누설», AUC 0.62 → 0.94). 동료도 global 0.812 vs
question-local 0.740 으로 같은 격차를 봤다 — **독립 재발견**이다.

**부수 소득 — 분산 법칙의 외부 교차검증.** 동료의 k 곡선은 32 에서 아직 상승 중이고
(64.68 → 67.22 → 68.45 → 69.31, 16→32 가 +0.86%p) 우리는 32 에서 포화해 48·64 가 무익했다.
표가 더 흩어지는 모델일수록 더 많은 표를 요구한다는 예측과 방향이 맞는다.

## 4. 결론

모델에 접목할 것은 없다. 가져온 것은 **판정 설계 하나(구간별 하한)** 이고, 적용해보니
우리 배포 구성이 통과했다. 나머지는 우리가 더 강한 증거로 이미 닫은 축이다.
